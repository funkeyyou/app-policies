## 維護

政策以 App 分目錄保存。新增 App 時建立目錄及獨立政策頁，並更新首頁和本文件。
實質修改政策時，請同步更新頁面中的更新／生效日期，並依各 App 的需要提供通知。
單純調整託管位置不變更政策內容或生效日期。
