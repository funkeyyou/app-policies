YomuReader AI 隱私權政策

生效日期：2026 年 9 月 4 日
最後更新：2026 年 9 月 4 日

YomuReader AI 是個人開發者提供的非官方閱讀輔助工具，用來閱讀カクヨム 上公開的作品並提供 AI 翻譯。 本 App 與株式会社KADOKAWA 及カクヨム 官方服務沒有任何提攜、授權或背書關係。

1. 資料控管者與聯絡方式

本 App 由個人開發者營運。若有隱私、資料刪除或 AI 內容相關問題，請聯絡：

funkeyyou@gmail.com

2. 本 App 不需要帳號

YomuReader AI 沒有註冊、登入或使用者帳號系統，也不會要求你提供 KAKUYOMU 的帳號密碼。 本 App 不會蒐集你的姓名、電話、通訊錄、定位、相機或麥克風資料，也沒有整合廣告或行為分析 SDK。

3. 保存在你裝置上的資料

以下資料只保存在你裝置的 App 私有儲存空間：

  • 書架、作品與章節目錄
  • 閱讀進度與閱讀歷史
  • 從公開網頁取得的日文原文與網頁快取
  • AI 翻譯、標題翻譯、章節摘要與前情提要
  • 術語庫、角色資料與翻譯偏好
  • 介面語言、外觀與閱讀設定

API Key 保存在 Android Keystore 保護的系統安全儲存區，不會寫入資料庫、備份檔或 App 紀錄。

你主動匯出的備份檔由你自己選擇儲存位置。備份不含 API Key，也不含日文原文。

4. 會離開裝置的資料

4.1 カクヨム

搜尋作品、匯入公開追蹤清單、加入作品或閱讀章節時，本 App 會直接從你的裝置連線至 https://kakuyomu.jp/。對方網站可能依其自身政策取得 IP 位址、時間、網址與 User-Agent 等一般網路紀錄。 本 App 不會傳送你的 KAKUYOMU 帳號或密碼，也不儲存登入 Cookie。

4.2 你指定的 WIKI 網頁

只有在你主動貼上網址並執行匯入時，本 App 才會讀取該公開網頁。該網站會依其自身政策處理一般網路紀錄。 擷取出的文字可能在下一步送往 AI 服務整理。

4.3 AI 服務

當你主動使用 AI 翻譯、標題／簡介翻譯、WIKI 整理、角色補全或前情提要時，本 App 會透過 HTTPS 將必要內容送往 開發者營運的固定端點，該端點再轉送至 OpenAI 官方 API 處理。依功能不同，請求可能包含：

  • API Key（作為授權資訊）
  • 你選擇的模型名稱
  • 作品名、章節名與待翻譯的日文內容
  • 與該章節相關的術語、角色、前文與章節摘要
  • 你設定的翻譯風格與補充說明
  • WIKI 網頁擷取的文字，或產生前情提要所需的既有譯文與摘要

開發者營運的中介端點：

  • 未啟用連線紀錄（access log）
  • 不保存 prompt、小說原文、WIKI 內容或模型回覆
  • 會保存與 API Key 相關的用量紀錄，用於額度管理；額度用盡即無法繼續使用

上游處理者為 OpenAI。依其官方說明，透過 API 送出的內容預設不會用於訓練模型； 濫用監控紀錄可能包含 prompt 與回覆，預設保留最多 30 天，法律要求或為防止危害時可能更久。 詳見 OpenAI 資料使用說明。

本 App 不會出售任何資料。

4.4 AI 內容回報

你可以在 App 內回報不當或有問題的 AI 產出（閱讀頁的 AI 面板，或「設定 → 關於」）。 回報透過表單轉寄服務 FormSubmit（Devro LABS）送到開發者信箱，依該服務說明，投稿會在其系統保留 30 天。

回報內容包含：你選擇的問題類型、你填寫的說明，以及只有在你勾選時才附上的 AI 產出節錄（最多 500 字）。 作品與章節以雜湊代碼標示，回報不含 API Key、完整章節或日文原文。

4.5 作者聯絡入口

點擊 LINE 連結會交由你的瀏覽器或 LINE 開啟；複製微信號只會寫入你裝置的剪貼簿。 後續資料處理由你選擇的通訊服務依其政策負責。

5. 權限用途

  • INTERNET：讀取公開小說與 WIKI 頁面，以及呼叫 AI 服務。
  • POST_NOTIFICATIONS：顯示你主動啟動的翻譯或匯入進度。
  • FOREGROUND_SERVICE、FOREGROUND_SERVICE_DATA_SYNC： 讓你主動啟動的長時間 AI 工作在螢幕關閉時繼續，並持續顯示通知。本 App 不會無故在背景啟動。

6. 你的控制權與資料刪除

你可以在 App 內：

  • 刪除單一章節、單一作品或全部翻譯快取
  • 刪除術語與角色資料
  • 清除閱讀歷史、原文快取與已儲存的 API Key
  • 移除書架上的作品
  • 選擇性匯出或匯入資料

解除安裝 App 會刪除裝置上的 App 私有資料。若要刪除開發者端點保存的用量紀錄， 或詢問已送出的 AI 內容回報，請來信 funkeyyou@gmail.com， 開發者會在合理期間內處理。OpenAI 端的濫用監控紀錄依其自身政策保留與刪除。

7. 安全措施

所有網路連線使用 HTTPS，App 也停用了明文連線。API Key 由 Android Keystore 保護， 不會寫入資料庫、備份檔或紀錄。沒有任何安全措施能保證絕對安全，請妥善保管你的 API Key 與自行匯出的備份檔。

8. 兒童

本 App 不以兒童為主要受眾。來源網站上的公開作品可能包含由原網站標示的暴力、性或其他成人向內容， 請依你所在地區的規定與自身年齡判斷是否使用。

9. 政策變更

本政策如有重大變更，開發者會更新本頁的生效日期，必要時在 App 內提供顯著通知。
